STRATUM / HOW IT WORKS

The building, in real time.

Choose a floor in the scene collection, then click a sensor to inspect its readings. Drag the timeline to explore history. LIVE returns to the current time.

Data source

Repository feed reads the Pi’s snapshot every 30 seconds. After the expiry interval (15 minutes by default), a sensor becomes offline. Local demo generates a year of simulated history in this browser; it does not upload anything. Published test data is also visibly labelled simulated.

Maps

The overlay fills every visible modeled floor footprint. Sensor markers respect wall occlusion in overview modes; floor mode shows them through walls. A finite-volume solver estimates a steady diffusion field between sensor readings, with lower conductance across modeled walls and open flow paths at doorways. Temperature runs blue → green → red; humidity runs green → blue.

This is a spatial estimate. Wall coefficients are relative assumptions; airflow, HVAC, real wall materials, and moisture transport are not measured. RH is interpolated as a scalar, not modeled as water-vapor mass transport. Regions without a connected sensor remain transparent.

Viewport controls

Middle drag: orbit. Shift + middle: pan. Scroll: zoom. Left-click: select sensor. Home: frame scene. Numpad 1 / 3 / 7: front / side / top. Right-drag also pans. Drag the panel dividers to resize the workspace.
